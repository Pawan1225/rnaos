# Solver Portfolio

## Overview

The Solver Portfolio executes optimization problems generated by the
Optimization Generator.

It provides a unified interface for classical, heuristic, hybrid,
and future quantum optimization backends.

---

## Components

### BaseSolver

Common interface implemented by every solver.

---

### GreedySolver

Deterministic baseline solver.

---

### SimulatedAnnealingSolver

Metaheuristic optimization using temperature-based search.

---

### GeneticSolver

Population-based evolutionary optimization.

---

### SolverRegistry

Maintains available solver implementations.

---

### SolverOrchestrator

Coordinates solver selection and execution.

---

## Pipeline

```text
OptimizationProfile
        │
        ▼
Solver Orchestrator
        │
        ▼
Solver Registry
        │
        ▼
Selected Solver
        │
        ▼
SolverResult
```

---

## Public API

```python
from solver_portfolio import SolverOrchestrator
```
