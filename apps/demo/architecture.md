# RNAOS Demo Architecture


## System Flow


User

↓

RNA Sequence Input

↓

Demo Engine

↓

RNAOS Pipeline

↓

Result Evaluation

↓

Demo Report


## Internal Components


### Input Layer

Responsibilities:

- Accept RNA sequence
- Validate nucleotide characters
- Prepare input data


### RNAOS Demo Engine

Responsibilities:

- Orchestrate RNAOS services
- Execute complete workflow
- Collect outputs


### Intelligence Layer

Includes:

- Biological Intelligence
- AI Intelligence
- ML/DL Components


### Optimization Layer

Responsibilities:

- Generate optimization problem
- Execute solver workflow
- Produce candidate structure


### Evaluation Layer

Responsibilities:

- Compare with reference
- Calculate metrics


Metrics:

- Structure accuracy
- Energy gap
- Runtime
- Quantum resource estimate


### Presentation Layer

Displays:

- Input sequence
- Predicted structure
- Reference structure
- Benchmark metrics
