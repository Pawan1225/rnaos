# ADR-003 — Why Next.js

Status: Accepted

Date: 2026-07-20

---

# Context

RNAOS requires a modern web interface for dashboards, experiment visualization, analytics, and interactive workflows.

---

# Decision

Next.js is selected as the frontend framework.

---

# Rationale

Benefits include:

- React ecosystem
- Server-side rendering
- App Router
- TypeScript support
- Strong performance
- Scalable project structure

---

# Consequences

Positive

- Modern UI
- Maintainable codebase
- Excellent developer experience

Negative

- Learning curve for advanced routing and rendering features
