# ADR-008 — Why qBraid

Status: Accepted

Date: 2026-07-20

---

# Context

RNAOS aims to execute quantum workflows across multiple hardware providers and simulators without vendor lock-in.

---

# Decision

qBraid is selected as the quantum execution and interoperability platform.

---

# Rationale

qBraid provides:

- Multi-provider access
- Cross-framework compatibility
- Cloud execution
- Hardware portability
- Simplified quantum workflow management

---

# Consequences

Positive

- Greater flexibility
- Easier experimentation across backends
- Reduced vendor dependence

Negative

- External platform dependency
- Potential API changes over time
